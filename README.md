# Мониторинг качества вывоза ТКО и соблюдения SLA подрядчиками 🚛 DataLens + Airflow

## 📌 Описание проекта
Бизнес-ориентированный проект по разработке аналитического дашборда для контроля качества вывоза Твердых Коммунальных Отходов (ТКО). Система позволяет отслеживать работу мусороуборочной техники в реальном времени, фиксировать нарушения графиков вывоза и автоматически рассчитывать уровень соблюдения SLA (Service Level Agreement) подрядчиками.

**🎯 Главный бизнес-результат:** Обеспечена стопроцентная прозрачность логистики для заказчиков и оператора. Создан инструмент оперативного контроля сбоев, что помогло снизить количество жалоб жителей на невывоз мусора на **25%**.

---

## 🛠️ Технологический стек
* **Языки и библиотеки:** `Python`, `Pandas`, `NumPy`, `GeoPy` (геокодирование)
* **Форматы данных:** `SQL`, `GeoJSON` (работа с полигонами и точками площадок)
* **Оркестрация и автоматизация:** `Apache Airflow` (ежедневный ETL-пайплайн)
* **Визуализация (BI):** `Yandex DataLens` (интерактивные гео-карты)

---

## 📐 Архитектура данных и этапы реализации

### 1. Сбор данных & ETL (Python / Airflow)
* Написан автоматический скрипт, собирающий сырые логи перемещения спецтехники (GPS-треки) и фактические отметки с весовых станций.
* Пайплайн обернут в **Apache Airflow DAG** для ежедневного регулярного сбора данных, очистки от дубликатов и проверки на аномалии по расписанию.

### 2. Гео-инженерия (GeoJSON)
* Текстовые адреса контейнерных площадок были очищены и переведены в точные географические координаты `[широта, долгота]` с помощью библиотеки `geopy`.
* Данные упакованы в формат **GeoJSON** для корректного отображения слоев на интерактивной карте.

### 3. Расчет метрик SLA
В процессе предобработки на Pandas были вычислены следующие ключевые показатели:
* **Доля просроченных выездов** (отношение сорванных графиков к общему числу запланированных).
* **Среднее время задержки** спецтехники на маршрутах.
* **Рейтинг критических адресов** (выявление точек с систематическими нарушениями вывоза).

### 4. Визуализация в Yandex DataLens
Разработан дашборд, включающий в себя:
* **Точечную карту площадок** с цветовой индикацией статуса вывоза (Зеленый — норма, Красный — критическая просрочка, Желтый — внимание).
* Фильтры по подрядчикам, районам города и временным периодам.
* Графики динамики нарушений для топ-менеджмента и CEO.
